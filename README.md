# AI娘扑克工坊

把AI娘立绘做成一副可以交给印厂制作的扑克牌。工具支持候选选图、历史保存、牌面排版、红黑花色分配、牌盒管理与CMYK印刷导出。

## 能做什么

- 自带85个图库候选；原画、预览与牌面文字分开管理，可导入新的角色图、牌背和六个盒面。
- 多选、大图查看、自动保存和历史恢复；随包保留28项当前选择与7条选择历史。
- 可拖动、缩放角标和模型名称区域，为各角色分配黑色、红色版本。
- 生成54张正面、1张统一牌背和6个盒面；输出RGB PNG看图稿与真正的CMYK JPG商家包。
- 每次导出冻结当时的选择、配置和素材，期间改选不会改变正在生成的内容。

## 下载与启动

推荐下载上方Release中的完整ZIP，包含工具、候选素材、字体及ICC。也可以克隆本仓库：

```bash
git clone https://github.com/Archwindos/ai-girls-poker-studio.git
cd ai-girls-poker-studio
```

需要Python 3.10或更新版本。Windows在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r 04-制作工具\requirements.txt
```

然后双击 **启动选图.cmd**，打开本地WebUI。启动器会寻找空闲端口，以它打开的地址为准。

绘图通过Codex或其他绘图环境完成，再把原画导入本工具。图像生成时请保留角标和模型名区域，文字由程序统一添加。

## 从选图到印刷

1. 在“素材与选图”中挑选或添加候选，需要时打开大图设置排版框。
2. 在“制作与导出”中指定每位角色的黑色、红色槽位，再指定统一牌背及六个盒面。
3. 保存配置，查看预览和缺项，然后生成发布成品与商家包。
4. 把商家ZIP交给印厂。54张正面各印一张，全部配同一张牌背，大小王也使用同一背面。

保存选择后，原画按版本输出到 `01-发布成品/当前选择`；每次导出另存到 `01-发布成品/导出批次`。

默认成品宽63×高88 mm，提交图67×92 mm，四边各留2 mm裁切余量，圆角半径4 mm。单张厚约0.3 mm，54张叠厚约16.2 mm。牌盒内部宽65×高90×厚18 mm；六面稿需由厂商按纸厚、粘口和插舌套刀模。

输出300 DPI，CMYK暂用PSO Coated v3，偏切±1 mm为检验假设，颜色以印厂打样为准。商家ZIP内只有61张CMYK JPG和简短说明，不含PDF；RGB PNG用于屏幕查看。

## 目录与版本

- `02-创作资产`：候选原画、预览、模型名称和逐图布局；盒前、盒背的原始插画在其 `原始插画` 子目录。
- `03-原始素材`：原始立绘与必要参考。
- `04-制作工具`：WebUI、排版导出代码、字体、ICC与详细使用说明。
- `05-制作记录/当前状态`：选择、历史和生产配置。
- `01-发布成品`：使用工具后生成的原画副本与印刷文件。

点数映射：A Llama、2混元、3 MiniMax、4 Mistral、5文心一言、6 Qwen、7 GLM、8 Kimi、9 Grok、10 DeepSeek、J Gemini、Q GPT、K Claude；大小王为豆包。黑桃/梅花共用黑色槽位，红桃/方块共用红色槽位。

本版已精简过程文件，保留全部图库候选与生产所需资源。盒前、盒背真实生成原图分别为1066×1476和1477×1065 px，较大的排版尺寸不代表原生2K。Windows已实机验收，其他系统尚未作实机验收。更多运行与维护说明见 `04-制作工具/工具说明.md`。
