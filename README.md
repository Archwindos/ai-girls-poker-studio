## 使用流程

1. 在 Codex 或其他绘图工具完成新画面，再用“添加候选”导入。
2. 勾选候选，查看大图，需要时设置角标和名称的排版框。选择自动保存，可恢复历史。
3. 在“制作与导出”分配各角色黑色、红色槽位，再指定统一牌背与六个盒面。
4. 保存配置后生成发布成品与商家包。导出冻结提交时的配置与素材，期间改选不会影响正在生成的内容。

## 文件位置

- `02-创作资产`：全部图库候选、生产原画、预览、名称及逐图排版；素材索引.csv列出保留资产。
- `02-创作资产/原始插画`：盒前和盒背的原始插画。
- `03-原始素材`：原立绘及必要参考。
- `04-制作工具`：WebUI、排版导出代码、字体、ICC及使用说明。
- `05-制作记录/当前状态`：当前选择、完整选择历史和制作配置。
- `01-发布成品/当前选择`：保存选择后按版本输出所选原画。
- `01-发布成品/导出批次`：每次生成的完整牌面、商家包和冻结快照。

## 印刷输出

每次生成54张正面、1张统一牌背、6个盒面。屏幕稿是RGB PNG；商家ZIP只含61张嵌ICC的CMYK JPG和简短说明，不含PDF。全部正面（含大小王）均配同一张牌背。

默认裁后卡牌宽63×高88 mm；提交图67×92 mm，四边各裁2 mm，圆角半径4 mm。单张厚约0.3 mm，54张叠厚约16.2 mm。牌盒内部宽65×高90×厚18 mm，六面稿需由厂商按纸厚、粘口和插舌套刀模。

输出300 DPI，ICC暂用PSO Coated v3，偏切±1 mm为检验假设，实际颜色以印厂打样为准。盒前、盒背真实生成原图为1066×1476、1477×1065 px；较大的排版图不代表原生2K。盒背横看，生产面稿已处理方向，不要重复旋转。

## 继续创作与移机

图像生成通过Codex或你选择的绘图环境完成，再导入工具。角色原画的牌点、花色、模型名应留空，由程序排版。A～10为单人，J/Q/K为上下连体。

当前牌点：A Llama、2混元、3 MiniMax、4 Mistral、5文心一言、6 Qwen、7 GLM、8 Kimi、9 Grok、10 DeepSeek、J Gemini、Q GPT、K Claude；大小王为豆包。黑桃/梅花共用黑色槽位，红桃/方块共用红色槽位。

复制本目录即可移机，无需旧output、归档或Codex缓存。可用build_release.py再次打包本包保留的素材。字体许可和ICC资料随工具保留；素材来源及品牌字标不统一声明为原创。Windows已验收，其他系统未作实机验收。
