# 新增一套设计

1. 从 `03-原始素材` 或统一素材库中取原立绘。对照图库已有角色，保留脸、发色、配饰和关键道具。
2. 在 Codex 使用内置绘图工具，或自行使用其他绘图工具生成。轻量包保留候选图及必要参考；完整过程提示词和生成记录保存在完整制作项目。未选中的画面也可以继续编辑。
3. 角色图只画人物和花边，牌点、花色、模型名由排版程序加上。A～10 是单人；J/Q/K 是上下连体；同一角色黑红服装可以不同，动作按当前设计要求保持一致。
4. 保存真实生成文件，记录提示词和参考图，不把普通放大后的像素数说成原生生成尺寸。
5. 在 WebUI 添加候选，给它一个新编号。不要覆盖旧版本。设置排版框，勾选并安排黑红槽位，再生成完整牌面。

本地工具不内置图像生成服务，也不保存或代用模型 API 密钥。图像生成阶段依赖你所使用的绘图环境，后续选图、历史、排版、印刷输出可在安装依赖后的本地运行。

牌盒导入的是设计好的六个面稿。背面群像横看，导入生产稿前应按盒面方向旋转一次；生产程序不再旋转。新盒面可在 WebUI 与旧面稿并列保存、切换。
